# Инструкции для работы над проектом

- Перед изменениями прочитайте [текущий статус аудита](docs/AUDIT_CURRENT.ru.md), [исходный аудит](docs/AUDIT.ru.md) и относящиеся к задаче части [плана](docs/AUDIT_NEXT_WORK.ru.md). Исходный аудит — снимок на коммите `bbfd5632a20e0dd58bf939243bdc50cdd4065844`, а не гарантия текущего состояния: сверяйте замечания с актуальным кодом, тестами и незакоммиченными изменениями.
- Пользовательские запросы и действующие вышестоящие инструкции имеют приоритет. План аудита — ориентир для продолжения работы, а не требование выполнять все этапы для каждой задачи.
- Сохраняйте чужие изменения. Используйте Blender со встроенным `pxr`; исходники NVIDIA Toolkit служат для сверки алгоритмов, а не обязательной runtime-зависимостью.
- Не записывайте в capture-слои и не перезаписывайте исходные текстуры. При работе с экспортом проверяйте существующие целевые данные и ошибки до записи.
- Не добавляйте суффиксы к экспортируемым именам текстур; при конфликте имён разных данных сообщайте об ошибке. Сохраняйте оригинальный hash материала при его замене.
- Превью захватов читаются непосредственно из папки захватов; не создавайте файловый кэш превью в каталоге аддона.
- Для существенных изменений добавляйте регрессионные тесты, проверяющие результат, и запускайте подходящие проверки в доступных версиях Blender. Отдельно указывайте, если поведение игры или RTX Remix runtime не проверено.
