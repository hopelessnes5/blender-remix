Texture Suffix Cleaner — графический интерфейс
=================================================

Содержимое архива:
  clean_mod_texture_suffixes.py       — обновлённый скрипт: конфликтующие DDS пропускаются
  clean_mod_texture_suffixes_gui.py   — графический интерфейс на Tkinter
  start_gui.bat                       — запуск интерфейса на Windows

Что нужно:
  1. Python 3 с Tkinter (обычно входит в стандартную установку Python).
  2. Blender с поддержкой USD / модулем pxr.

Запуск на Windows:
  1. Распакуйте все файлы в одну папку.
  2. Запустите start_gui.bat (или clean_mod_texture_suffixes_gui.py).
  3. Выберите папку мода и укажите blender.exe, если он не найден автоматически.
  4. Нажмите «Проверить изменения».
  5. Изучите список переименований и изменения ссылок.
  6. Если всё верно, нажмите «Применить изменения» и подтвердите действие.

Запуск на Linux/macOS:
  python3 clean_mod_texture_suffixes_gui.py

Важно:
  - «Проверить изменения» НЕ модифицирует файлы.
  - Перед применением автоматически создается ZIP-копия оригиналов
    в <папка мода>/.suffix-cleanup-backups/.
  - Если целевое имя DDS уже занято, файл пропускается без перезаписи.
  - Если несколько DDS дают одно целевое имя, пропускаются все такие файлы.
  - Ссылки USD на пропущенные DDS не изменяются.
  - В журнале строки SKIP и количество пропущенных конфликтов.
  - Другие проверки безопасности продолжают действовать.
  - Capture-слои не изменяются.
  - Бинарные USD-слои блокируют операцию, как и в оригинальном скрипте.
  - GUI работает обычным Python, а исходный скрипт запускает через Blender.
  - Оба Python-файла должны оставаться рядом.
