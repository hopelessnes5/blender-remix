# Очистка суффиксов текстур мода

Скрипт `tools/clean_mod_texture_suffixes.py` анализирует одну папку мода.
Он убирает экспортные окончания `.a.rtex`, `.n.rtex`, `.r.rtex`, `.m.rtex`,
`.e.rtex`, `.s.rtex`, `.o.rtex` перед `.dds`, в том числе старый вариант с
хешем и `.oct`. Части исходных имён, например `_Normal`, остаются. Ссылки
на переименовываемые файлы в текстовых USD-слоях внутри мода обновляются.

Скрипт использует `pxr` из Blender. Укажите путь к своему `blender.exe` и папку
одного мода. Сначала выполните анализ без записи:

```powershell
& "ПУТЬ\blender.exe" --background --python "F:\repos\blender-remix\tools\clean_mod_texture_suffixes.py" -- "ПУТЬ\rtx-remix\mods\ИМЯ_МОДА"
```

Команда выводит переименования и изменения строк USD. Чтобы применить их,
добавьте `--apply` после пути к моду. Сначала создаётся и проверяется ZIP
с исходными файлами в `ИМЯ_МОДА\.suffix-cleanup-backups\`; затем выполняются
изменения. При обнаруженной ошибке записи скрипт пытается восстановить файлы.

Проверьте результат анализа: при совпадении имён скрипт останавливается,
не перезаписывая файлы. Capture-слои не изменяются; если такой слой внутри
папки мода ссылается на переименовываемую текстуру, операция блокируется.
Бинарный или нераспознанный USD внутри папки также блокирует операцию,
поскольку скрипт не может безопасно исправить в нём ссылки. Ссылки за пределы
выбранной папки не меняются; перед запуском убедитесь, что другие проекты не
ссылаются на файлы внутри неё.

Для ручного восстановления по ZIP сначала удалите переименованные файлы,
перечисленные в `_cleanup_manifest.json` внутри архива, затем извлеките
исходные файлы из архива поверх папки мода. Это восстановит их состояние на
момент запуска, поэтому учитывайте последующие правки. Сам файл манифеста
извлекать в папку мода не нужно.
