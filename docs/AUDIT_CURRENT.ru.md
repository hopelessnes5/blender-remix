# Текущий статус аудита

Основа — [исходный аудит](AUDIT.ru.md) коммита `bbfd5632a20e0dd58bf939243bdc50cdd4065844`. Ниже приведён статус работы после него. Изменения могут быть незакоммиченными; перед началом проверьте `git status` и фактический код. Аудит не является исчерпывающим доказательством отсутствия других дефектов.

На последней объединённой проверке на копии проекта в Blender 4.5.5 и 5.1.2 прошли 224 теста из 224. Игровой RTX Remix runtime не проверялся.

| Замечание | Статус и оставшиеся границы |
|---|---|
| A01 | Закрыто: `rtx_remix_importer.write_guard` — общий guard (capture, `permissionToEdit`, capture edit target), подключён ко всем точкам сохранения слоёв (project_ops, hide_ops, asset_manager_ops, copier, hide, export_operator, `ProjectComposition.save`) и повторяется непосредственно перед каждой записью. Оставшаяся граница: принадлежность цели проекту проверяется только через UI-скан проекта, data-level проверки нет. |
| A02 | Закрыто: `TextureProcessor.is_source_target` (сравнение realpath + `os.path.samefile`, до проверки texconv) защищает height- и normal-экспорт; источники — `bl_image.filepath` и `remix_normal_source_path`. Жёсткие ссылки и симлинки отклоняются, байты источника не меняются, отличная цель экспортируется. Другие писатели проверены: конвертеры dds↔png пишут только PNG во временные пути, MDL-копирование пропускает samefile-алиасы. Границы: samefile сравнивает только существующие файлы, тома без хардлинков переводят тесты в skipTest, игровой RTX Remix runtime не проверялся. |
| A03 | Частично: подготовка изображений и загрузка Blender выполняются в главном потоке и проверяют его; фоновые конвертеры получают подготовленные файлы, async callbacks передаются на event loop вызывающего кода. Event loop, запущенный вне главного потока, не гарантирует безопасный доступ callback к bpy. Основной экспорт синхронен и может блокировать интерфейс; lifecycle заданий при отключении аддона — A26. |
| A04 | Частично: неудачная конвертация не считается успехом; очередь различает успех, ошибку и отмену и сохраняет информацию об ошибке. При timeout/отмене уже запущенный texconv может завершиться и записать DDS после возврата: остановка процесса и предотвращение поздней записи остаются открытыми. |
| A05 | Частично: export_material подготавливает DDS на целевом томе и откатывает их публикацию и изменения edit-layer при ошибке; mesh ingest удерживает транзакцию до Save и обрабатывает исключение или False. У material replacement/light DDS публикуются до позднего Save общего target-layer, поэтому его сбой ещё не откатывает файлы. Частичная запись самого USD при реальном дисковом сбое не проверена; полный атомарный экспорт не заявляется. |
| A06–A07 | Не закрыты: сброс default против слабого слоя и старые authored inputs. |
| A08 | Экспорт и определение типа материала используют шейдер активного Material Output, поддерживают Reroute и явно отклоняют неподдерживаемый Surface. Более сложные графы не поддерживаются. |
| A09 | Импорт scalar maps подключает красный канал. Проверены ноды, вычисления полноценным рендером не проверены. |
| A10 | Для scalar слотов поддержаны Alpha, R/G/B и преобразование Color в значение; неподдерживаемые вычисления отклоняются. Остальная обработка графов, Normal Map Strength и все комбинации карт не закрыты. |
| A11 | Известные кодировки octahedral и DirectX декодируются в упакованную OpenGL-копию для Blender; исходная кодировка и путь сохраняются. При экспорте учитываются выбранный режим и переименование пользователем. Неизвестная кодировка не угадывается; неполная композиция Apply Mod, повторные копии и игровой runtime требуют дальнейшей проверки. |
| A12 | DDS fallback упаковывает декодированный PNG до удаления временного файла, сохраняя путь исходного DDS. Проверены упаковка, сохранение и повторное открытие .blend отдельным процессом в Blender 4.5 и 5.1. |
| A13–A14 | Не закрыты: устаревшие DDS и конфликты между материалами. |
| A15 | Исправлено чтение граней после пропущенной вырожденной грани; topology и UV проверены регрессионным тестом. |

| A18 | Добавлено чтение стандартного `UsdGeom.Mesh.normals` при отсутствии primvar. Покрыта faceVarying, более широкий roundtrip ещё требует проверки. |
