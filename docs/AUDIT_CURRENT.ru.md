# Текущий статус аудита

Основа — [исходный аудит](AUDIT.ru.md) коммита `bbfd5632a20e0dd58bf939243bdc50cdd4065844`. Ниже приведён статус работы после него. Изменения могут быть незакоммиченными; перед началом проверьте `git status` и фактический код. Аудит не является исчерпывающим доказательством отсутствия других дефектов.

На последней объединённой проверке на копии проекта в Blender 4.5.5 и 5.1.2 прошли 195 тестов из 195. Игровой RTX Remix runtime не проверялся.
